Comment obtenir votre clé d'accès (une seule fois)

  1. Allez sur github.com/settings/tokens?type=beta
  2. Tapez sur "Generate new token"
  3. Nom : "Publication annonces"
  4. Expiration : au choix (1 an conseillé)
  5. Repository access → "Only select repositories" → choisissez andrea-bernard-immobilier
  6. Permissions → Contents → passez sur "Read and write"
  7. Générez, copiez la clé (elle commence par github_pat_), collez-la ci-dessus
